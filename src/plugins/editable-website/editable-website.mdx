# Editable Website & Live Preview Plugin

Premium **Editable Website & Live Preview** plugin — bidirectional iframe sync between the CMS entry editor and your frontend. Works with the recommended [SvelteKit Site Starter + Svedit](/docs/development/site-starter.mdx) (same repo) or any decoupled frontend (Astro, Next.js, Vue) that implements the `postMessage` protocol.

## Features

| Feature            | Description                                                                                        |
| :----------------- | :------------------------------------------------------------------------------------------------- |
| Live preview       | Real-time content preview in an iframe as you edit                                                 |
| Bidirectional sync | Preview → CMS via `svelty:save` and `svelty:document:update` (v1.2)                                |
| Visual editing     | Click-to-edit — `data-svelty-field` markers focus the CMS form                                     |
| Reverse highlight  | Focusing a CMS field scrolls to and highlights the matching preview element                        |
| Block palette      | Add / move / delete hero, paragraph, CTA and image blocks; flip paragraph ↔ hero ↔ CTA             |
| Media on page      | Drop or pick an image; upload runs through `/api/media/upload`; focal point by click or arrow keys |
| Mobile edit mode   | Hold the bottom pill to toggle editing ↔ read-only preview on touch devices                        |
| Autosave & publish | Debounced autosave or one-click publish; both go through the workflow-gated save lane              |
| Split canvas       | Desktop + mobile frames receive every update (one post per frame)                                  |
| Site starter       | Same-origin preview with [Website Starter](/docs/development/site-starter.mdx) preset              |
| Dynamic origin     | `livePreview` URL pattern — relative or absolute frontend URL                                      |
| Preview tokens     | Signed tokens via `POST /api/preview/authorize`                                                    |
| Agent access       | WebMCP `get_live_preview_url` returns a signed draft URL after `update_entry` writes               |
| Handshake protocol | Framework-agnostic `postMessage` (SvelteKit, Astro, React, Vue)                                    |
| Multi-collection   | Per-collection via `livePreview` + `plugins: ["editable-website"]`                                 |

## How It Works

1. **Collection schema** sets `livePreview` (URL pattern) and `plugins: ["editable-website"]`
2. **Preview URL** — `POST /api/preview/authorize` returns a signed `previewUrl`
3. **Handshake** — iframe sends `svelty:init`; CMS responds with `svelty:update`
4. **CMS → preview** — form edits are coalesced (60 ms) and posted to every mounted frame
5. **Preview → CMS** — field clicks focus the form; document/save messages merge into the entry and can autosave or publish through the workflow-gated lane

## Configuration

Set `livePreview` on your collection schema (string pattern or `true` for same-origin site starter):

```typescript
{
  name: "pages",
  livePreview: "/{slug}?lang={lang}",
  plugins: ["editable-website"],
  fields: [ /* ... */ ]
}
```

For external frontends (Astro, Next.js), use a full URL pattern:

```typescript
{
  livePreview: "https://myfrontend.com/{slug}?lang={lang}",
  fields: [ /* ... */ ]
}
```

### Site starter (recommended, free core + paid bridge)

The **Website Starter** preset seeds a `pages` collection, publishes a Svedit homepage, and **auto-enables** this plugin (trial starts on setup). The **public site is free**; the plugin unlocks **visual editing from the CMS**.

- `SITE_STARTER_ENABLED: true` — guests see `/` with Svedit blocks (the Website Starter preset sets this)
- `SITE_STARTER_ENABLED: false` (default) — pure headless; `/` redirects to login
- **Without license/trial** — edit pages via the CMS form; Live Preview tab shows an upgrade prompt
