# Last 5 Media Widget

Modern "Last 5 Media" widget showing recent uploads with thumbnail previews. Adaptive layouts: horizontal file chips at height 1, rich scrollable cards at height 2+.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature       | Description                               |
| :------------ | :---------------------------------------- |
| Thumbnails    | Image previews for recent uploads         |
| File metadata | Name, type, and upload timestamp per item |
| Compact mode  | Horizontal file chips (h:1 widget size)   |
| Rich layout   | Scrollable media cards (h:2+ widget size) |
| Click-through | Items link to the media gallery           |
| Auto-polling  | Data refreshes every 30 seconds           |

---

## Data Source

| Endpoint                        | Description                        |
| :------------------------------ | :--------------------------------- |
| `GET /api/dashboard/last5media` | Most recently uploaded media items |
