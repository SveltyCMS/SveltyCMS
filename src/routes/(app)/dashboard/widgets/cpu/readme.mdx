# CPU Usage Widget

Real-time CPU usage monitoring with support for dynamic sizing, light/dark mode, and accessibility. Compact mode shows overall utilization; larger sizes add per-core breakdowns.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature        | Description                                         |
| :------------- | :-------------------------------------------------- |
| Overall usage  | Total CPU utilization percentage                    |
| Per-core stats | Individual core utilization bars (h:2+ widget size) |
| Load average   | System load indicator                               |
| Compact mode   | Single-row utilization chip (h:1 widget size)       |
| Auto-polling   | Data refreshes every 5 seconds                      |

---

## Data Source

| Endpoint                                  | Description                       |
| :---------------------------------------- | :-------------------------------- |
| `GET /api/dashboard/system-info?type=cpu` | CPU model, cores, and utilization |
