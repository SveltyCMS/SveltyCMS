# System Messages Widget

Important system notifications with severity indicators. Messages are derived from recent audit activity and categorized by severity so admins never miss critical events.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature         | Description                                     |
| :-------------- | :---------------------------------------------- |
| Severity badges | Low / medium / high / critical indicators       |
| Recent messages | Latest system notifications (default 10)        |
| Action context  | Related action and actor attribution            |
| Compact mode    | Single-row notification chips (h:1 widget size) |
| Rich layout     | Expandable message cards (h:2+ widget size)     |
| Auto-polling    | Data refreshes every 30 seconds                 |

---

## Data Source

| Endpoint                             | Description                                    |
| :----------------------------------- | :--------------------------------------------- |
| `GET /api/dashboard/system-messages` | Recent system messages categorized by severity |
