# Performance Monitor Widget

Track system performance metrics including response times, error rates, and throughput, with client-side history sparklines for trend visualization.

---

## 💰 Licensing

**Premium extension** with a **14-day free trial** (no key required). After the trial expires a valid marketplace license is required — the widget then shows an upgrade prompt. Pricing is configured in the marketplace listing.

### License Verification

The widget checks license status via the internal API on mount:

```
GET /api/system/license-status?type=dashboard&id=performance
```

---

## Features

| Feature           | Description                               |
| :---------------- | :---------------------------------------- |
| Response time     | Current and average API response latency  |
| Error rate        | Failed request ratio                      |
| Throughput        | Request volume indicator                  |
| History sparkline | Client-side trend chart of recent metrics |
| Compact mode      | Single-row metric chips (h:1 widget size) |
| Rich layout       | Detailed metric cards (h:2+ widget size)  |
| Auto-polling      | Data refreshes every 10 seconds           |

---

## Data Source

| Endpoint                                   | Description                                          |
| :----------------------------------------- | :--------------------------------------------------- |
| `GET /api/dashboard/metrics?detailed=true` | Full `MetricsService` report with system information |
