# Disk Usage Widget

High-performance disk usage widget using native CSS + SVG with multi-disk support. Shows total, used, and free space with usage bars for the root filesystem and any mounted volumes.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature      | Description                                  |
| :----------- | :------------------------------------------- |
| Multi-disk   | Root and additional mounted filesystems      |
| Usage bars   | Native SVG/CSS utilization indicators        |
| Free space   | Available space with formatted sizes (GB/TB) |
| Used percent | Percentage of disk consumed                  |
| Compact mode | Single-row summary (h:1 widget size)         |
| Auto-polling | Data refreshes every 10 seconds              |

---

## Data Source

| Endpoint                                   | Description                    |
| :----------------------------------------- | :----------------------------- |
| `GET /api/dashboard/system-info?type=disk` | Per-filesystem disk statistics |
