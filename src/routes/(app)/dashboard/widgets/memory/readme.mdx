# Memory Usage Widget

Real-time memory usage monitoring with formatted used/total values and utilization bars. Compact mode shows a single usage chip; larger sizes add detailed breakdowns.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature      | Description                             |
| :----------- | :-------------------------------------- |
| Used / total | Formatted memory values (MB/GB)         |
| Utilization  | Percentage bar with color-coded status  |
| Compact mode | Single-row usage chip (h:1 widget size) |
| Rich layout  | Detailed breakdown (h:2+ widget size)   |
| Auto-polling | Data refreshes every 10 seconds         |

---

## Data Source

| Endpoint                                     | Description                   |
| :------------------------------------------- | :---------------------------- |
| `GET /api/dashboard/system-info?type=memory` | Memory totals and free memory |
