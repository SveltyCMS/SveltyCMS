# Online Users Widget

Shows currently active users with role indicators and session details. Session duration is estimated from expiry minus the configured session TTL — no `Math.random()`.

---

## 💰 Licensing

**Premium extension** with a **14-day free trial** (no key required). After the trial expires a valid marketplace license is required — the widget then shows an upgrade prompt. Pricing is configured in the marketplace listing.

### License Verification

The widget checks license status via the internal API on mount:

```
GET /api/system/license-status?type=dashboard&id=user-online
```

---

## Features

| Feature         | Description                                  |
| :-------------- | :------------------------------------------- |
| Active sessions | Users with live sessions                     |
| Role indicators | Role badge per user                          |
| Session info    | Estimated session duration and last activity |
| Compact mode    | Count chip with avatars (h:1 widget size)    |
| Rich layout     | Detailed user list (h:2+ widget size)        |
| Auto-polling    | Data refreshes every 45 seconds              |

## Data Source

| Endpoint                         | Description                |
| :------------------------------- | :------------------------- |
| `GET /api/dashboard/online-user` | Users with active sessions |
