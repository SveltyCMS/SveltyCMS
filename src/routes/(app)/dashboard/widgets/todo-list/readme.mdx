# TODO List Widget

The **TODO List** dashboard widget allows administrators to organize, add, and complete daily maintenance tasks and pending content approvals directly from their main SveltyCMS dashboard.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature          | Description                                           |
| :--------------- | :---------------------------------------------------- |
| Add task         | Create a new task from the inline input               |
| Toggle complete  | Mark tasks as done / open with a single click         |
| Delete task      | Remove tasks that are no longer relevant              |
| Open-task badge  | Live count of pending tasks in the widget header      |
| Client-side only | No API dependency — works offline, state is in-memory |
| Compact mode     | Fits the default 1×1 grid cell                        |
