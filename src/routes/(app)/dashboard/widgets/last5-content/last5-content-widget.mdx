# Last 5 Content Widget

Clean, performant "Last 5 Content" widget with a modern responsive layout. Surfaces the most recently updated content entries across all collections so editors can jump back into active work quickly.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature            | Description                                   |
| :----------------- | :-------------------------------------------- |
| Recent entries     | Latest updated content across all collections |
| Collection badge   | Collection name shown per entry               |
| Relative dates     | "2h ago" style timestamps                     |
| Author attribution | Creator shown per entry                       |
| Click-through      | Entries link to their editor pages            |
| Compact mode       | Condensed list (h:1 widget size)              |
| Auto-polling       | Data refreshes every 30 seconds               |

---

## Data Source

| Endpoint                           | Description                                                 |
| :--------------------------------- | :---------------------------------------------------------- |
| `GET /api/dashboard/last5-content` | Recent content via `LocalCMS.collections.search` (limit: 5) |
