# System Health Widget

Monitor system services and overall health with a live status feed, uptime, per-service latency sparklines, and a one-click system reinitialize action.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature            | Description                                              |
| :----------------- | :------------------------------------------------------- |
| Overall status     | READY / DEGRADED / FAILED / INITIALIZING state indicator |
| Service feed       | Per-service health cards (database, auth, cache, …)      |
| Uptime             | System uptime display                                    |
| Latency sparklines | Native SVG trend charts per service                      |
| Reinitialize       | One-click system reinitialization action (admin)         |
| Compact mode       | Status chips (h:1 widget size)                           |
| Rich layout        | Full service feed (h:2+ widget size)                     |
| Auto-polling       | Data refreshes every 5 seconds                           |

---

## Data Source

| Endpoint                    | Description                       |
| :-------------------------- | :-------------------------------- |
| `GET /api/dashboard/health` | System health status and services |
