# Media Storage Analytics Widget

Media library storage analytics with quota tracking, file-type breakdown, and actionable insights. Compact summary at height 1, rich breakdown with quota bar and category cards at height 2+.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature        | Description                                       |
| :------------- | :------------------------------------------------ |
| Total assets   | Asset count and formatted total storage           |
| Quota usage    | Storage quota bar with percentage                 |
| Type breakdown | Distribution by media type (image, video, …)      |
| Insights       | Actionable storage recommendations                |
| Compact mode   | Single-row summary (h:1 widget size)              |
| Rich layout    | Quota bar + category breakdown (h:2+ widget size) |
| Auto-polling   | Data refreshes every 60 seconds                   |

---

## Data Source

| Endpoint                   | Description                            |
| :------------------------- | :------------------------------------- |
| `GET /api/media/analytics` | Media storage usage and type breakdown |
