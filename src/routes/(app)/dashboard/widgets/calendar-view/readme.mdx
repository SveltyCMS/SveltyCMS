# Calendar View Widget

The **Calendar View** dashboard widget gives administrators a clear calendar overview of upcoming content publications, scheduled meetings, and project milestones directly on their main dashboard.

---

## 💰 Licensing

**Included with SveltyCMS** — free for all installations.

---

## Features

| Feature         | Description                                     |
| :-------------- | :---------------------------------------------- |
| Month grid      | Full month view with weekday headers            |
| Navigation      | Previous / next month controls                  |
| Event dots      | Visual markers on days with scheduled items     |
| Today highlight | Current day emphasized with the primary color   |
| Client-side     | No API dependency — sample events are in-memory |
| Rich layout     | Designed for the default 2×2 grid cell          |
