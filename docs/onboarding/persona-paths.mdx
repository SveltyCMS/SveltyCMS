# Persona Paths

SveltyCMS serves diverse roles across engineering, operations, and marketing teams. Select your role below for a tailored onboarding journey.

---

## ✍️ Path 1: For Content Creators & Editors

As an editor, your focus is authoring, reviewing, and publishing structured content quickly and reliably.

### Creator Workflows {#creator-workflows}

1. **Navigating the Content Tree**: Access collections from the left sidebar.
2. **Authoring Rich Content**: Use the TipTap-powered RichText widget with Markdown shortcuts and image embedding.
3. **Drafts & Versions**: Create drafts, preview revisions, and schedule release dates.
4. **Localization (i18n)**: Author multi-language versions side-by-side (`translated: true` fields). Admin chrome uses Paraglide (EN/DE by default) — see [System Languages](../guides/configuration/system-languages.mdx).

## 🛡️ Path 2: For Administrators & Security Teams

As an administrator, your focus is user governance, tenant boundaries, and auditability.

### Admin Workflows {#admin-workflows}

1. **Access Management**: Create roles, assign granular permissions, and enforce 2FA.
2. **SCIM 2.0 & SSO Provisioning**: Configure enterprise IdP provisioning (Okta, Azure AD, SAML).
3. **System Audit Logs**: Inspect tamper-evident crypto-chained audit ledgers.
4. **Rate Limiting & Threat Mitigation**: Configure IP rate limiting and adaptive security guards.

👉 **Recommended Reading**:

- **[Access Management Reference](../reference/api/auth.mdx)**
- **[Security Architecture](../reference/security/index.mdx)**

## 💻 Path 3: For Full-Stack Engineers & Developers

As a developer, your focus is data modeling, custom widgets, API consumption, and headless frontend integration.

### Developer Workflows {#developer-workflows}

1. **Schema**: Define collections in the Collection Builder or as TypeScript under `config/collections/`.
2. **LocalCMS**: From SvelteKit server files, call `locals.cms` instead of HTTP.
3. **HTTP**: From a separate frontend, call REST or GraphQL.
4. **Widgets**: A custom field is a widget (definition, input, display), written with Svelte 5 runes.
