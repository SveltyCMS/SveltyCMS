# Setup wizard walkthrough

You are on `/setup`. Install commands are [Getting started](../getting-started.mdx). Field rules, error text, and the seven blueprints are the [setup wizard guide](../guides/configuration/setup-wizard.mdx).

## 1. Database

Pick an engine and test the connection before Next.

| Engine          | When it fits                              | What you enter                                       |
| :-------------- | :---------------------------------------- | :--------------------------------------------------- |
| SQLite          | Local development and a single small site | Nothing. The wizard creates `./db/sveltycms.db`.     |
| PostgreSQL      | More than one app instance                | Host, port `5432`, database, user, password          |
| MariaDB / MySQL | A typical VPS                             | Host, port `3306`, database, user, password          |
| MongoDB         | A document database or Atlas              | A `mongodb://` or `mongodb+srv://` connection string |

If the database already has tables, the wizard asks before it replaces them.

## 2. Admin account

- **Username** is 2–50 characters: letters, numbers, and `@ $ ! % * # . _ -`.
- **Email** must be a valid address.
- **Password** is at least 8 characters and includes lower case, upper case, a number, and a symbol. Confirm it on the same step.
- Two-factor authentication can wait until the user profile.

## 3. Site and blueprint

Set the site name, the production URL (`https://…`), and the admin and content languages. English and German ship compiled. Extra language codes are written when setup completes.

The country field starts on Germany: euro, German shop text, 19% and 7%. Change the country and the currency, shop language, and tax fields update. Choose “Choose later”, or clear the standard rate, and no tax row is created. Germany, Austria, and Switzerland suggest German shop text. Every other country suggests English. The suggested rates were checked on 5 October 2026. They are a starting point, not a tax ruling.

Then pick one blueprint. **Website Starter** is the recommended default. It creates `pages` and seeds Home, a legal page, and Privacy. The legal page is Impressum for Germany, Austria, and Switzerland, Mentions légales for France, Aviso legal for Spain, Note legali for Italy, Bedrijfsgegevens for the Netherlands, and Legal notice otherwise. Replace that text before a public launch. The other cards are Blog, Agency, SaaS, Corporate, E-commerce, and Blank. Each card lists the collections it creates. The list is in the [setup wizard guide](../guides/configuration/setup-wizard.mdx#solution-presets-starter-kits).

Multi-tenant mode, Redis, and cloud media storage are on this step and can stay off.

## 4. Email

Optional. Skip it and set SMTP later in settings. If you fill it in, send the test message before Next.

## 5. Review and complete

Read the summary. Complete writes the admin user, the blueprint collections, and `config/private.ts`, then signs you in. You land on the first collection, or on `/login` when the blueprint created none (Blank).

## After setup

- `/setup` redirects to `/login`.
- `/api/setup` answers `403`.
- With Website Starter, open `/` for the homepage, then replace the text on the legal page and on Privacy.
- Connection settings stay in `config/private.ts`. Running the wizard again means pointing it at a database that has no administrator yet. See [recovery](../guides/configuration/setup-wizard.mdx#troubleshooting).
- A shop is the E-commerce blueprint, then the Commerce plugin. Continue in [E-commerce](../guides/content/ecommerce.mdx).
