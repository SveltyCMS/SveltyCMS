## 🔌 Unwired Capabilities & Technical Debt

Existing modules to be connected or formally retired:

- **Database-Native FTS** — Wire `IFtsAdapter` (`dbAdapter.fts` across SQLite FTS5, Postgres `tsvector`, MariaDB `MATCH...AGAINST`, Mongo `$text`) into the live `?search=` query pipeline with tenant scoping and field-level access controls.
- **Semantic Index Persistence** — Implement incremental updates and disk persistence (`indexItem`, `indexBatch`, `persistSemanticIndex`, `rebuildSemanticIndex`) in `src/services/intelligence/semantic-index.ts`.
- **Content Insights Consumer** — Document and surface `getContentInsights` and cross-tenant pattern recognition in editorial workflows.
- **`TRUSTED_PROXIES`** — Enforce `getTrustedProxies()` from `src/databases/config-state.ts` across IP extraction in rate limiting, auth, and audit logging.
- **Role Bitset Invalidation** — Automate role cache clearing on role permission mutations via `invalidateRoleBitset`.
- **`streamingRawJsonResponse`** — Wire or prune unused streaming helper in `src/routes/api/[...path]/handlers/streaming.ts`.
- **Required-Fields Publish Guard** — Connect `validateRequiredFields()` (`src/widgets/widget-validation.ts`) to status transition mutations to enforce non-empty publish requirements.
- **Legacy Store Bridges** — Migrate `systemState` and `overallState` in `src/stores/system/state.svelte.ts` from legacy `svelte/store` `derived()` exports to modern Svelte 5 runes (`$state()`, `$derived()`).
- **GraphQL Replay & Hint Controls** — `markMutationExecuted` (mutation replay prevention) and `createSuppressHintsRule` in `src/routes/api/graphql/rules.ts` are never wired (`+server.ts` only registers depth-limit and max-alias rules). Wire them into the Yoga validation list or delete them deliberately — as-is the replay guard does not exist at runtime.
- **Background Services Out of the API Process** — `hooks.server.ts` still statically imports the job queue, scheduler, outbox, watchdog, automation, telemetry, and behavioral learner and starts them at READY (an earlier `await import()` left their production exports `undefined` under Rolldown's cyclic-chunk initializers). A dedicated `background-entry.ts` must be started from `index.cjs` **as a separate process** — importing it into the same process evaluates the modules and frees nothing. Prerequisites: child-process DB init, supervision/restart, heartbeat reporting back to the parent's service health, and an explicit decision for SQLite (WAL + `PRAGMA busy_timeout=30000` already tolerate a second writer, but `withWriteLock` is per-process, so the two processes would serialize at the file level — contention, not corruption; a busy API burst could park a background poll for up to the timeout). Projected: 30–80 MB resident, ~5–10% on `create`, 0–3% on cached reads.
- **API-Only Build Profile** — a second build that emits only the read lane, the write lane, and the active adapter (no admin routes, no widget catalog, no session/security admin chrome). This is the step that moves resident memory again; the cached-read rate stays at the PostgreSQL HTTP floor either way. A comparator process (two lists, admin build off) cannot be met by trimming unused widgets or background services.

## 🚀 Future & Enterprise Initiatives

- **Cross-Source Data Merge (v3.1)**: Federated queries across heterogeneous databases.
- **Visual Studio Query Builder**: In-app drag-and-drop visual pipeline builder for complex database aggregations.
- **GraphQL Supergraph & Federation**: Apollo Federation v2 compatibility for multi-service enterprise architectures.
- **Svelty Managed Cloud & Enterprise Cluster**: Automated multi-region clustering, distributed Redis caching, and Terraform infrastructure recipes.
- **Zero-Downtime Deployment Verifier**: Automated pre-flight deployment check verifying schema backward-compatibility.
- **SvelteKit 3.0 & TypeScript 7 Adoption**: Finalize upgrade path once upstream `@sveltejs/kit` and `write_tsconfig` stabilize.
- **Rust Tooling Evaluation (`fuzdev/tsv`)** — evaluated 2026-09-21; recommendation: **stay with `oxfmt`**, which already ships the needed capability behind a disabled flag. `tsv` 0.4.1 is faster but not _more capable_.
  - `oxfmt` (pinned `^0.68.0`) has a top-level `svelte` key: "Pass `true` or an object to enable `.svelte` file formatting … Default: Disabled", and it loads `svelte/compiler` at runtime — **`svelte@^5.57.1` is already a direct dependency here**. Its `overrides` key supplies per-glob options, so `.svelte` can keep its own style. Measured with a throwaway config (`"svelte": {}` plus a `**/*.svelte` override on tabs / single quotes / no trailing commas): `oxfmt --check src` covers **1470 files in 1.59 s** (1024 → +446 `.svelte`) while `src/**/*.ts` (918 files) stays clean. With the key omitted, oxfmt matches **0 of 489** `.svelte` files. Reproduce: `bun x oxfmt -c <probe.json> --check src`.
  - **`tsv` 0.4.1 is not idempotent** on 2 of 446 `.svelte` files (`src/widgets/custom/seo/input.svelte`, `src/routes/(app)/dashboard/widgets/unified-metrics/index.svelte`): a generic argument list left as `}>(` + object is revised to `}>({` on the second pass, so a single-pass `--check` gate reports those two indefinitely. `oxfmt` reaches a fixed point on the first pass (verified on the same file), which is what a CI gate requires.
  - `tsv`'s advantage is throughput, not coverage: ~0.14 s for 446 `.svelte` files against `oxfmt`'s ~1.6 s for a whole-`src` pass — immaterial at this repo size. Its costs are a second toolchain, a layout that disagrees with `oxfmt`'s in detail (a later switch would mean a second reformat), a hardcoded non-configurable style, and no linter (it does not replace `oxlint`).
  - Whichever tool is chosen, the first run normalizes the backlog: ~427 of 446 `.svelte` files change, because nothing has ever formatted them. The diffs are layout-only — re-wrapping hand-compacted lines past 100 columns, e.g. the one-line `case 'sm': return { … }` arms in `src/components/ui/checkbox.svelte`.
- **Third-Party Security Audit**: Commission an independent external penetration test prior to enterprise GA.
