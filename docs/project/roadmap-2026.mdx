## ✅ Shipped — Adapter list / count (August 2026)

Product-layer APIs equal on SQLite, PostgreSQL, MariaDB, MongoDB:

- [x] `crud.findPage` — limit+1 `hasMore`, optional total, keyset `cursor`
- [x] `CountMode` (`exact` | `estimate` | `auto`) + dialect estimates
- [x] L1 count cache (30s) + invalidation with collection writes
- [x] Unit + integration contracts (`find-page-count-contract`, `page-utils`)
- [x] CollectionService list path: limit+1 + cached `crud.count` when filters are equality-only
- [x] Status facets via `crud.count` (L1-backed)
- [x] Users list: `findPage` on `auth_users` when no text search
- [x] Media `getByFolder`: limit+1 + parallel count
- [x] Website tokens: Mongo `findPage`; SQL limit+1 trim; Smart Table **saved views**
- [x] Schema proxy: `db.<collection>.findPage(...)`

**Still open (call-site polish):** multi-column sort UI, bulk field-edit, export filtered selection, team/cloud saved views.

## 📊 CMS Tables & List Platform (Smart Table)

- [x] AES-256-GCM encryption of TOTP secrets at rest
- [x] Pending setup state — resumable 2FA enrollment
- [x] Trusted devices cookie
