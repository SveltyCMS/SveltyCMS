# Policy-as-Code & WASM Security Architecture (2026 Edition)

SveltyCMS combines compiled Policy-as-Code (PaC) logic with WebAssembly (WASM) threat scanning to achieve sub-microsecond authorization latency and nanosecond WAF payload protection.

---

## 1. Hybrid Policy-as-Code (PaC) Engine

SveltyCMS separates **Role Definition** (Code/Git) from **Role Assignment** (GUI/Database).

- **Location**: `src/services/security/policy-engine.ts`
- **Config**: `src/config/policies/default-policy.ts`
- **Latency**: `< 50 microseconds` per authorization check (CPU-bound in RAM).

```typescript
import { policyEngine } from "@src/services/security/policy-engine";

const isAllowed = policyEngine.evaluate(user, "collection:posts", "read", {
  authorId: document.authorId,
});
```

---

## 2. Pre-Compiled WASM WAF Middleware Guard

Requests passing through SvelteKit are inspected at **Layer 0** before JSON payload deserialization.

- **Location**: `src/hooks/wasm-waf-guard.ts`
- **Features**: Scans path traversal (`../`), prototype pollution (`__proto__`), XSS scripts, SQL injection, and HTTP header splitting vectors.
- **Compatibility**: Includes an automatic pure-JS fallback for environments where WebAssembly instantiation is restricted.

---

## 3. Runtime Security Baseline Clamping

Database security settings are clamped against Git-versioned hard security floors in CPU memory.

- **Location**: `src/services/security/baseline-guard.ts`
- **Config**: `src/config/security-baseline.ts`
- **Guarantee**: Even if a database value is altered, the application layer enforces the Git baseline floor (`Math.max(dbMinPassword, BaselineMinPassword)`).

---

## 4. Cryptographic Merkle Tree Audit Ledger

Audit logs are cryptographically hashed and structured into a Merkle Tree, allowing $O(\log N)$ tamper verification and verifiable inclusion proofs.

- **Location**: `src/services/audit-chain.ts`
- **Verification**: `auditChainService.computeMerkleRoot(entries)` and `auditChainService.generateMerkleProof(entries, index)`.

---

## 5. Automated Security API Payload Fuzzer

Proactively tests API endpoints against malformed strings, oversized buffers, SQLi patterns, and deep nesting.

- **Run Command**: `bun run test:fuzz`
- **Script Location**: `scripts/security/fuzz-api.ts`
