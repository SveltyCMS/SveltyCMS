# SveltyCMS documentation

SveltyCMS is a self-hosted CMS. Editors use the admin. Other apps use REST or GraphQL. Server code inside this project uses LocalCMS. The same collections run on SQLite, PostgreSQL, MariaDB, or MongoDB.

New here? Read [Concepts](./concepts/index.mdx) (one page), then [Getting started](./getting-started.mdx).

## Product in one table

| Piece         | What it is                                                             |
| :------------ | :--------------------------------------------------------------------- |
| **Admin**     | SvelteKit 3 (RC), Svelte 5 runes, Tailwind CSS v4                      |
| **Content**   | Collections compiled from `config/collections/` by ContentSync         |
| **Fields**    | Widgets: definition, input, and display                                |
| **APIs**      | REST, GraphQL, and LocalCMS for in-process server calls                |
| **Databases** | SQLite, PostgreSQL, MariaDB, MongoDB through adapters                  |
| **Tenancy**   | `tenantId` on stored records                                           |
| **Auth**      | Argon2id, optional TOTP, role permissions, account lockout             |
| **Languages** | Paraglide for admin chrome; localized fields for content               |
| **Container** | `ghcr.io/sveltycms/sveltycms` — SQLite by default, `amd64` and `arm64` |

Measured throughput lives only in [Performance benchmarks](./project/benchmarks/index.mdx), with the run date and the command that produced it. A comparison with other CMSs, written against public sources, is in [Competitive comparison](./project/competitive-comparison.mdx).

Security reporting: [security@sveltycms.com](mailto:security@sveltycms.com) · [GitHub Advisories](https://github.com/SveltyCMS/SveltyCMS/security/advisories). The control list is the [Security reference](./reference/security/index.mdx).
