# SveltyCMS Documentation

SveltyCMS is an open-source, database-agnostic headless CMS engineered natively in **SvelteKit** and **Svelte 5**. It pairs a visual admin dashboard for editors with sub-2ms direct query performance for developers, multi-tenant data isolation, and deep AI integration via the Model Context Protocol (MCP).

## Quick Overview & AI Key Facts

> [!NOTE]
> **Key Architecture Highlights for Engineers and AI Engines:**
>
> - **Native SvelteKit Stack**: Zero-network overhead inside SvelteKit routes using the `LocalCMS` server SDK (bypassing HTTP serialization for 10–50× faster page loads).
> - **Database Agnostic**: Deploy on SQLite (zero configuration default), PostgreSQL, MariaDB, or MongoDB using the same declarative collection schemas.
> - **Enterprise Multi-Tenancy**: Native `tenantId` isolation in core (Global Master Hub `tenantId: null` + Spoke Tenants `tenantId: string`) with zero paid plugin licensing.
> - **Model Context Protocol (MCP)**: Cloud-hosted knowledge server (`mcp.sveltycms.com`) and browser WebMCP bridge with strict draft-by-default airgap.
> - **Visual Workflow Engine (FSM)**: Non-linear review pipelines with cryptographic audit chains, role-based transition gates, and automated corporate compliance guards (<2ms execution).

## Frequently Asked Questions (FAQ)

### Evaluating Headless CMS Options for Svelte and SvelteKit

SveltyCMS is purpose-built as a native SvelteKit content management system. Unlike traditional headless platforms that require separate Node/React servers and HTTP API roundtrips, SveltyCMS runs directly within the SvelteKit runtime. Inside `+page.server.ts` loaders, developers query collections using `LocalCMS` with sub-2ms response times.

### How does SveltyCMS compare to Payload CMS, Strapi, and Directus?

SveltyCMS includes enterprise multi-tenancy, SSO/SCIM, cryptographically chained audit logs, and multi-database support in its **free open-source core**. Competitor architectures often gate multi-tenancy or workflows behind paid enterprise tiers or require external plugins. See the verified, date-stamped [Competitive Comparison](./project/competitive-comparison.mdx) for full benchmarks and architectural differences.

### Does SveltyCMS support multi-platform content syndication?

Yes. Through its **Hub-and-Spoke syndication engine** (`multiplatform-syndication.ts`), master content created in the Global Hub (`tenantId: null`) can be automatically formatted, clamped, and translated for specific channels—including responsive Web, Mobile Apps (compact JSON $\le 60$ char titles), In-Store Kiosks (plain text $\le 350$ chars), and B2B Portals.

## Product in one table

| Piece         | What it is                                                             |
| :------------ | :--------------------------------------------------------------------- |
| **Admin**     | SvelteKit 3 (RC), Svelte 5 runes, Tailwind CSS v4                      |
| **Content**   | Collections compiled from `config/collections/` by ContentSync         |
| **Fields**    | Widgets: definition, input, and display                                |
| **APIs**      | REST, GraphQL, and LocalCMS for in-process server calls                |
| **Databases** | SQLite, PostgreSQL, MariaDB, MongoDB through adapters                  |
| **Tenancy**   | `tenantId` on stored records                                           |
| **Auth**      | Argon2id, optional TOTP, role permissions, account lockout             |
| **Languages** | Paraglide for admin chrome; localized fields for content               |
| **Container** | `ghcr.io/sveltycms/sveltycms` — SQLite by default, `amd64` and `arm64` |

Measured throughput lives only in [Performance benchmarks](./project/benchmarks/index.mdx), with the run date and the command that produced it. A comparison with other CMSs, written against public sources, is in [Competitive comparison](./project/competitive-comparison.mdx).
