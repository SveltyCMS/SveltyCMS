## 🏗️ Core Concept: The 3 Pillars

Every widget consists of a **Definition**, an **Input**, and a **Display** component. This separation ensures that logic and UI remain decoupled and performant.

## 🧪 Testing Policy

- **Core Widgets**: Tests are located in `tests/unit/widgets/core/`.
- **Custom Widgets**: Tests are located in `tests/unit/widgets/custom/` or the widget's own folder.

## 🧩 Notable Custom Widgets

- **[Block Builder Widget](../../reference/components/fields.mdx#visual-polymorphic-block-builder-widget)**: Visual polymorphic layout constructor (`src/widgets/custom/block-builder/`) featuring 8 built-in presets (Hero, Text & Prose, Media Showcase, Call to Action, Features Grid, Quote/Testimonial, FAQ, Rich Text), interactive reordering, and Valibot schema validation.
