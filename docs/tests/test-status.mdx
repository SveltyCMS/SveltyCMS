# Test Status

> [!IMPORTANT]
> **Live pass/fail counts = GitHub Actions** on this branch or PR. Numbers in docs drift; CI does not.  
> This page is the **only** test-status dashboard — route maps, inventories, and deep strategy live in the linked docs below (no separate archive).

**Dashboard updated:** 2026-09-04 — **Transformer v6 + schema-loader lean pass**. Unit suite **473 files / 4066 tests** green; `bun run check` clean. Compilation: composite transformer now descends after schema `_id`/`tenantId` injection and injects deterministic widget-call `uuid`s on the first-argument object literal — widget calls under exported `schema.fields` are rewritten to `globalThis.widgets.*` (regression suite drives the real `compile()` against a checked-in fixture; byte-deterministic). Schema loader: widgets proxy installed once (not per file), confinement roots + case-insensitive widget map precomputed, worker-pool dummy timeout removed, single-pass schema hash. Boot-path probe: 150 compiled schemas in 42 ms. Benchmark tooling now reports CMS throughput as **% of raw HTTP floor** (the honest HTTP yardstick); 2026-09-04 SQLite baselines recorded (cold 3049 RPS · TURBO-HIT 5478 RPS @8c).
