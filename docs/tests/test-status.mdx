| When       | What runs (summary)                                                                                                                                       |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pre-commit | 1. DB safety 2. Format + lint (`check`) 3. Lint-staged 4. **`risk:audit`** 5. **Unit** 6. SBOM sync (if lock/package changed)                             |

| Manual     | `bun run test:doctor` · `bun run test:security` · `bun run test:e2e`                                                                                      |
| CI         | Whitebox (format/lint/check/unit/tenant/secrets/probe) → build → db-tests (4 DBs) → E2E prep + groups → benchmarks                                        |
