# Access Management (`/config/access-management`)

## Surface

| Piece                   | Role                                                                               |
| ----------------------- | ---------------------------------------------------------------------------------- |
| `+page.server.ts`       | Admin-only load; slim roles + permission catalog                                   |
| `+page.svelte`          | Tabs load on demand; header Save/Reset posts to `/api/user/update-roles`           |
| `permissions.svelte`    | Permission matrix vs roles; per-row `?` help tooltip from `Permission.description` |

### Product notes (2026-07-19)

- Create-role modal: `modalState.trigger(Component, props, response)` — response is **3rd arg**, not buried in props.
- Save/Reset render in the `PageTitle` header (not `StickyActions`) so the fixed toast region can't overlay them.
- Permission rows show a `?` help tooltip when `Permission.description` is set; descriptions live in `src/databases/auth/core-permissions.ts`.
- Roles drag-reorder: `handleRoleDrop` uses `insertAt = fromIndex < targetIndex ? targetIndex - 1 : targetIndex` (pre-removal→post-removal index shift).
- Website tokens: `$effect` density/column sync is change-gated to avoid `effect_update_depth_exceeded` on tab open.
