# Media Gallery (`/mediagallery`) — Control Map

## Surface

| Area   | Files                                                                  |
| ------ | ---------------------------------------------------------------------- |
| Shell  | `+page.svelte`, `+page.server.ts`                                      |
| Views  | `media-grid.svelte`, `media-table.svelte`, `virtual-media-grid.svelte` |
| Upload | `upload-media/*` (local + remote)                                      |
| Modals | advanced search, focal, transcode, image editor                        |

Media content is environment-specific; tests seed via upload.

Gallery first paint: tiles use `mediaDisplayUrl()` (not the original); SSR rows are `toGalleryListItem()` allowlists (no `advancedMetadata` / embeddings); published-in-use ids come from `getPublishedReferencedIds()` (one index rebuild); Sharp/`MediaService` is imported only from upload/delete actions; image editor / details / table / advanced-search / tag-editor / drag-preview / folder-prompt shells load on demand.

> **Drop row (2026-09-22):** `@thisux/sveltednd` runs in **pointer** mode
> (document-level `pointermove`/`pointerup` + `elementFromPoint` at release), and
> the sidebar rows only become droppables _while_ a drag is in flight
> (`externalDrop.enabled = isMediaDragActive` in `media-folders.svelte`). The spec
> therefore drives `page.mouse.down()` → `move()` → `up()` and asserts
> `data-media-drop-target` **mid-drag**; probing that attribute before the gesture
> always returned empty and fell back to the current-folder breadcrumb, whose drop
> is a documented no-op.
