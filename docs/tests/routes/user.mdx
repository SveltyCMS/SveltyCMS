## Product notes

- Every user preference entry carries a `?` help tooltip (`helpTitle()` → `userpage_help_*` Paraglide messages): identity badges (role, user id, tenant), identity fields (username, email, password), security (2FA, passkeys, sessions, magic link, OAuth, permissions), and preferences (appearance, density, card style, reduced motion, high contrast, collaboration, RTC, privacy).
- Settings → appearance: the density and card-style `Select`s render a custom label row plus a help icon and pass `ariaLabel` (E2E still targets `select[aria-label="Density"]`).
