Security: remediate GHSA vulnerabilities (Privilege Esc, XSS, SSRF)

This commit implements defense-in-depth remediation and regression 
tests for three critical vulnerability classes, alongside GraphQL 
hardening and CI scanner enhancements.

Privilege Escalation (CWE-269):
- Implemented `stripPrivilegedUserFields()` policy to drop `role` 
  and `isAdmin` from client payloads.
- Enforced fail-closed privilege dropping at both the handler 
  (`auth.ts`) and adapter layers.

Stored XSS via SVG Upload (CWE-79):
- Closed large-file stream bypass by forcing all `.svg` uploads 
  through `bufferAndSanitizeSvg()`.
- Enforced strict `MAX_SVG_BYTES` (5 MiB) ceiling.
- Added CSP `script-src 'none'` to `/files/` serving routes.

SSRF in Remote Upload (CWE-918):
- Replaced raw `fetch()` in remote actions with safe helper 
  `MediaService.saveRemoteMedia()`.
- `validateEgressUrl` and `safeFetch` now explicitly block cloud 
  metadata (169.254.169.254), loopback, RFC1918, and DNS rebinding.

Defense-in-Depth & Testing:
- Gated GraphQL Subscriptions requiring `context.user` auth.
- Added AST static scanner rules (`scan-security-risk.ts`) for 
  `ssrf-unguarded-fetch` and `privilege-adapter-unguarded`.
- Expanded `bun run test:security` suite with 28+ regression cases.
